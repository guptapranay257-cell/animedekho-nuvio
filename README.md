# animedekho-nuvio

AnimeDekho plugin for **Nuvio** — Hindi dubbed anime series and movies (multi-audio, multi-server).

## Install in Nuvio
1. Open **Nuvio** → **Settings → Local Scrapers**
2. Add this repository URL:
   `https://raw.githubusercontent.com/guptapranay257-cell/animedekho-nuvio/main/manifest.json`
3. Enable **AnimeDekho** and restart Nuvio.
